Image-to-3D Face Reconstruction · DECA + FLAME

Single-photograph 3D face reconstruction with DECA and the FLAME 2020 model on the RPTU Elwetritsch HPC — feature-preserving coarse and detail meshes, an exact surface-distance metric suite, and a phantom-to-patient validation ladder toward surgical use.

DECA FLAME 2020 3D reconstruction PyTorch HPC / Slurm Medical validation

Highlights

  • Reconstructs feature-preserving 3D face meshes (coarse FLAME shape + displacement-based detail) from a single 2D photograph, running as a Slurm pipeline on RPTU's Elwetritsch HPC.
  • Built a float64 surface-distance metric suite — chamfer, Hausdorff, HD95, point-to-surface RMSE / MAE / P95, and signed bias — validated against analytic ground truth (translation and sphere self-tests) to machine precision.
  • Per-region error reporting (nose, cheeks, chin, forehead, periorbital), because a good global average can hide a locally poor region — critical for surgical relevance.
  • Fully deterministic and reproducible: fixed seeds, deterministic CUDA workspace, and per-experiment logging of Slurm job IDs and git commits.
  • Defined a four-step validation ladder: software self-test (done) → textured-phantom study against exact printed-STL ground truth → volunteer study with metrology-grade scans → patient data under ethics approval, with pre-agreed acceptance thresholds (RMSE ≤ 2 mm, HD95 ≤ 3 mm).
