Pasta Shape Classification

AI-driven pasta-shape classifier for the food industry — quality control, sorting, packaging, and inventory management — running real-time on a live camera feed. Transfer learning compensates for a deliberately small hand-collected dataset (56 / 7 / 7 train / val / test).

Computer vision Transfer learning PyTorch Real-time inference Quality control

Highlights

  • Classifies multiple pasta types from a live camera feed to support automated quality control, sorting, packaging, and inventory management in food-industry workflows.
  • Transfer learning over a hand-collected dataset (56 training / 7 validation / 7 test samples) — 70% top-1 on the held-out test set despite the deliberately small data budget.
  • Training reached ≈78% train and ≈95% validation accuracy (train / val loss ≈ 0.7 / 0.2), demonstrating that a targeted fine-tuning strategy transfers well to small industrial datasets.
  • Deployed as a real-time inference loop against a mounted camera rig, so the same model that trained on stills also runs on the live sorting line.
